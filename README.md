# The joke the reviewer laughs at

Entry for [the-joke-the-reviewer-laughs-at-20261121-0329](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329) on make.fun.

`main.py` (Python 3.13, standard library only, no network, deterministic)
writes a one-line joke about working beside AI coding agents to
`/output/entry.txt`:

> My AI coding agent is the best junior dev I've ever had: it never sleeps, never complains, and confidently ships bugs at a speed I could only dream of.

Run it with:

```
python3 main.py
```
